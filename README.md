# اتصال به درگاه پرداخت پینو پی

[![Tests](https://github.com/OR81/pino-pay-integrations/actions/workflows/tests.yml/badge.svg)](https://github.com/OR81/pino-pay-integrations/actions/workflows/tests.yml)
[![Latest release](https://img.shields.io/github/v/release/OR81/pino-pay-integrations)](https://github.com/OR81/pino-pay-integrations/releases/latest)

ماژول‌های آماده برای وصل کردن سایت به درگاه پرداخت [پینو پی](https://pay.pinosite.ir). این مخزن دو بسته دارد:

| بسته | برای چه کسی | نصب | راهنمای کامل |
| --- | --- | --- | --- |
| **پکیج لاراول** | سایت‌هایی که با لاراول نوشته شده‌اند | Composer | [docs/laravel.md](docs/laravel.md) |
| **افزونهٔ ووکامرس** | فروشگاه‌های وردپرسی با ووکامرس | فایل zip در وردپرس | [راهنمای افزونه](wordpress/pino-pay-for-woocommerce/README.md) |

از زبان یا پلتفرم دیگری استفاده می‌کنید؟ مستندات API و نمونه‌کد PHP، Node.js و Python در [pay.pinosite.ir/docs](https://pay.pinosite.ir/docs) است.

## پیش از شروع

در هر حالت این چهار قدم لازم است:

1. در [پینو پی ثبت‌نام کنید](https://pay.pinosite.ir/register) و کد ملی و شماره شبا را در پنل کامل کنید.
2. حساب را برای بررسی بفرستید. نتیجه پیامک می‌شود.
3. در بخش «درگاه‌ها» برای سایت‌تان یک درگاه با دامنهٔ همان سایت بسازید و منتظر تأیید آن بمانید.
4. کلید درگاه (`merchant_id`) را از صفحهٔ درگاه بردارید. این کلید را فقط سمت سرور نگه دارید.

تا پیش از تأیید هم می‌توانید با همین کلید در [محیط آزمایشی](#محیط-آزمایشی) اتصال را کامل و تست کنید.

## شروع سریع

### لاراول

```bash
composer config repositories.pino-pay vcs https://github.com/OR81/pino-pay-integrations
composer require pinosite/laravel-pino-pay
```

در `.env`:

```dotenv
PINO_PAY_MERCHANT_ID=کلید-درگاه-شما
```

```php
use PinoSite\PinoPay\Facades\PinoPay;

// فرستادن مشتری به درگاه. مبلغ به ریال است.
$payment = PinoPay::request(1000000, route('payment.back'), 'سفارش ۱۲');
$order->update(['authority' => $payment->authority]);

return $payment->redirect();
```

```php
// برگشت مشتری: پرداخت را با مبلغ سفارش خودتان تأیید کنید.
$result = PinoPay::verify($order->authority, $order->amount);

if ($result->isFirst()) {
    // سفارش را تحویل دهید. کد پیگیری: $result->refId
}
```

مثال کامل با کنترلر، مدیریت خطا و بررسی زمان‌بندی‌شده در [docs/laravel.md](docs/laravel.md) است.

### ووکامرس

1. فایل [pino-pay-for-woocommerce.zip](https://github.com/OR81/pino-pay-integrations/releases/latest/download/pino-pay-for-woocommerce.zip) را دانلود کنید.
2. در پیشخوان وردپرس: افزونه‌ها، افزودن، بارگذاری افزونه. فایل را بارگذاری و افزونه را فعال کنید.
3. در ووکامرس، پیکربندی، پرداخت‌ها، گزینهٔ «پینو پی» را باز کنید، کلید درگاه را بگذارید و آن را فعال کنید.

جزئیات در [راهنمای افزونه](wordpress/pino-pay-for-woocommerce/README.md) است.

## مسیر پرداخت

1. سرور سایت شما از پینو پی درخواست پرداخت می‌کند و `authority` و آدرس پرداخت می‌گیرد.
2. مشتری به آدرس پرداخت می‌رود و از آنجا به درگاه بانکی منتقل می‌شود و پرداخت می‌کند.
3. مشتری به پینو پی برمی‌گردد. پینو پی پرداخت را از درگاه بانکی تأیید می‌کند.
4. مشتری به آدرس بازگشت سایت شما با `Authority` و `Status` هدایت می‌شود.
5. سرور شما پرداخت را از پینو پی تأیید می‌کند و اگر کد ۱۰۰ گرفت، سفارش را تحویل می‌دهد.

هر دو بسته این مسیر را انجام می‌دهند. این چند نکته را همیشه در نظر داشته باشید:

- **`Status` از مرورگر مشتری می‌آید و قابل جعل است.** سفارش را فقط بعد از پاسخ موفق تأیید پرداخت (`verify`) تحویل دهید.
- **مبلغ را از سفارش خودتان بخوانید،** نه از آدرس بازگشت.
- **همهٔ مبلغ‌ها به ریال است.** اگر قیمت‌های شما به تومان است، در ۱۰ ضرب کنید. افزونهٔ ووکامرس این تبدیل را خودش انجام می‌دهد.
- **کارمزد از سهم شما کم می‌شود** و مشتری همان مبلغ سفارش را می‌پردازد.
- **آدرس بازگشت باید روی دامنهٔ ثبت‌شدهٔ درگاه یا زیردامنه‌های آن باشد.**
- **مبلغ با تأیید درگاه بانکی برای شما ثبت می‌شود،** حتی اگر مشتری به سایت شما برنگردد. برای همین باید پرداخت‌های تأییدنشده را دوره‌ای بررسی کنید تا سفارشی جا نماند. افزونهٔ ووکامرس این کار را هر ساعت انجام می‌دهد و نمونهٔ آن برای لاراول در [راهنما](docs/laravel.md#بررسی-پرداختهای-تأییدنشده) آمده است.

## محیط آزمایشی

در محیط آزمایشی پولی جابه‌جا نمی‌شود و به جای درگاه بانکی صفحه‌ای با دو دکمهٔ «پرداخت موفق» و «پرداخت ناموفق» می‌بینید. این محیط پیش از تأیید حساب و درگاه هم کار می‌کند و آدرس بازگشت می‌تواند هر آدرسی باشد، حتی `localhost`.

- **لاراول:** `PINO_PAY_SANDBOX=true` در `.env`
- **ووکامرس:** گزینهٔ «حالت آزمایشی» در تنظیمات درگاه

> [!WARNING]
> حالت آزمایشی را روی سایت واقعی روشن نگذارید. در این حالت هر کسی می‌تواند با یک کلیک و بدون پرداخت، سفارش را تکمیل کند.

## کدهای خطا

| کد | معنی |
| --- | --- |
| `-9` | ورودی‌ها معتبر نیستند؛ ایراد هر فیلد جدا برمی‌گردد |
| `-10` | کلید درگاه معتبر نیست |
| `-11` | درگاه فعال نیست؛ هنوز تأیید نشده، رد یا معلق شده است |
| `-12` | حساب پذیرنده فعال نیست |
| `-13` | آدرس بازگشت روی دامنهٔ درگاه نیست |
| `-14` | مبلغ خارج از محدودهٔ مجاز است |
| `-15` | تعداد درخواست‌ها بیش از حد مجاز است (۱۲۰ درخواست در دقیقه برای هر کلید) |
| `-50` | مبلغ با مبلغ تراکنش یکی نیست |
| `-51` | تراکنش پرداخت نشده است |
| `-52` | مهلت پرداخت تمام شده است |
| `-54` | تراکنشی با این `authority` پیدا نشد |
